# My Viber Bot

ဒါဟာ Python နဲ့ ရေးသားထားတဲ့ Viber Bot ပရောဂျက်ဖြစ်ပါတယ်။

## Features (ပါဝင်တဲ့ လုပ်ဆောင်ချက်များ)
* အလိုအလျောက် စာပြန်ပေးခြင်း (Auto Reply)
* အသုံးပြုသူများထံသို့ သတင်းအချက်အလက်များ ပေးပို့ခြင်း

## How to Setup (ဘယ်လိုအသုံးပြုမလဲ)
၁။ Repository ကို Clone လုပ်ပါ။
၂။ လိုအပ်သော library များကို install လုပ်ပါ။
   ```bash
   pip install viberbot flask
